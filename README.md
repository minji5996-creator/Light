# 다양한 빛의 효과 · Lighting Lab

30가지 조명 기법의 배치, 빛의 방향과 명암을 비교하는 인터랙티브 웹사이트입니다.

- 3점 조명 개별 켜기·끄기
- 조명별 배치도와 명암 개념도
- 캐릭터 적용 이미지 6종
- 모바일 화면 지원

## 실행

이 저장소 루트에서 `python -m http.server 8000`을 실행하고 http://localhost:8000 에 접속합니다. 별도 빌드가 필요 없습니다.

## GitHub Pages

Settings → Pages → Deploy from a branch → main / (root)로 설정합니다.

배치도와 AI 생성 이미지는 교육용 개념 예시이며 정확한 광학 시뮬레이션과 차이가 있습니다.
